# MatrixQR - Premium Tech QR Code Studio

MatrixQR is a clean, modern, and high-performance client-side QR Code generator built with Tailwind CSS v4, Lucide Icons, and QRCode.js. It supports multiple languages and works entirely offline with zero server overhead.

🚀 **Live Demo:** https://<your-github-username>.github.io/<your-repo-name>/

## 🌟 Features
* **Multiple Formats:** Supports WiFi Network configurations, Communications Phone numbers, and vCard Electronic Business Cards.
* **Multi-Language UI:** Fully localized in English, Deutsch, Italiano, Türkçe, 한국어, and 简体中文.
* **High Performance:** Pure client-side JavaScript rendering with exceptional cross-browser canvas compatibility.
* **Premium Tech UI:** Matrix-inspired dark tech aesthetic with fully responsive grid layouts.

## 🛠️ Tech Stack
* [Tailwind CSS v4](https://tailwindcss.com/) - Rapid UI development
* [Lucide Icons](https://lucide.dev/) - Pixel-perfect open-source icons
* [QRCode.js](https://github.com/davidshimjs/qrcodejs) - Cross-browser QR Code generation engine

## 📂 Quick Start
1. Clone this repository or download the `index.html` file.
2. Open `index.html` directly in any browser—no installation, `npm install`, or server required!

### 简体中文说明

MatrixQR 是一款基于纯前端的高级科技感二维码生成终端，支持免服务器本地运行。

#### 功能亮点
* **多场景支持**：支持 WiFi 自动连接、手机号呼叫、国际化 vCard 电子名片生成。
* **六国语言联动**：内置英、德、意、土、韩、中六国语言包，UI 与输入提示实时同步切换。
* **零开销极速渲染**：采用高兼容性经典引擎，解决部分浏览器 Canvas 渲染失败的痛点。
